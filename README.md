# About
Landing page criada para servir de site para a empresa de telas chamada "Telas Vênus". 
O intuito da página é redirecionar os clientes para o whatsapp da empresa e com isso ter atendimento, ou redirecionar para o catálogo, para ver os produtos disponíveis, ou ainda redirecionar para a avaliação do google, onde podem dar nota para a empresa e para os produtos e atendimento recebido.

# Sobre a empresa:
Telas Vênus é uma empresa familiar localizada em Lagoa Santa (anteriormente localizada no bairro Saudade, em Belo Horizonte).
A empresa oferece atendimento personalizado, humanizado e com agilidade.
